# DhanWiser Design System

## Direction: Midnight Ledger

DhanWiser is a precise personal finance product: calm, private, and decisive.
The base is near-black charcoal with warm-white type. Citron is reserved for
the primary action and positive money movement; violet is a secondary accent.

## Rules

- Use the 4-point spacing grid in `DhanWiserTokens`; screens use 20px side padding.
- Use `DhanWiserSurface` for cards, rows, and grouped settings.
- Use `DhanWiserSectionHeader` for every titled collection.
- Primary actions are filled citron buttons; destructive actions use error red.
- Amounts use numeric text styling so columns do not jump as values change.
- Cards are 16px rounded, sheets 28px top-rounded, and inputs 10px rounded.
